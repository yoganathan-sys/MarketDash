# MarketDash

MarketDash is a PHP-based market dashboard project.

## Files

- `Supermain.php` - main dashboard page
- `add.php` - add records
- `del.php` - delete records
- `upd.php` - update form
- `update.php` - process updates

## Running locally

Place the project in the XAMPP `htdocs` directory, start Apache, and open:

`http://localhost/project/Supermain.php`
